Writing the Methodology chapter

Chapter 3 tells your examiner exactly how you answered each research question, and why that was the right way to answer it. This guide walks through the four subsections every economics Methodology chapter needs, then the knowledge you need to write each one well.

Ten things examiners look for in Chapter 3

  1. A clear line from each research question to a method. The examiner should be able to point at any RQ and find the data, variables and model that answer it.
  2. Choices that are justified, not just described. “I used stratified sampling” is a description. “I stratified by state because consumption differs sharply between East and West Malaysia” is a justification.
  3. A sampling design you can defend, including the population, sampling frame, selection procedure, sample size and response rate.
  4. A sample size that matches what you want to infer: precision for a proportion, or power for a hypothesis test. A population size alone is not a justification.
  5. Every variable operationalised: the question that measures it, its level of measurement and its coding.
  6. An instrument with a known pedigree: which scales were adopted, which adapted, and the evidence of validity and reliability in your sample.
  7. A model written for your data structure, with the right subscripts (\(i\), \(t\), \(it\)) and every symbol defined.
  8. An estimator chosen for the outcome variable (binary, ordinal, count, continuous) and for the identification problem.
  9. Transparent data handling: what was cleaned, recoded or dropped, and why.
  10. Honest limits: what your design can and cannot support, stated before the results.

How to use this guide

Parts of a section
Most sections are split into Notes, Worked example, Write-up, Worksheet and Quiz. The tabs under each title switch between them.
Model answers
Each worksheet question has a “Show model answer” button. Write your own answer first; the answer box keeps it in this browser.
Examiner's notes
Red-pen notes in the margin point out what examiners query most often. Hide them with the pen button in the top bar.
Projector mode
For teaching: the text grows to 26px and the contents fold away. The A− and A+ buttons adjust text size at any time.
Code
Examples come in Stata and Python; the switch on any code block changes all of them. The same code is in the downloadable do-files and notebooks, which run without errors.
Offline copy
Download the whole guide as one ZIP from F4 Downloads and open it without an internet connection.

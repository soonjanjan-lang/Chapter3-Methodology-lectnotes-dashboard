C2Data structures and how the model is written

Cross-section, time series, pooled cross-sections and panel data answer different questions, and each changes how you write the econometric model: which subscripts appear, which terms you add, and which estimator you use.

  • About 30 minutes
  • Four example datasets
  • Stata and Python estimation

After this section you can:

  1. recognise the four data structures from a dataset's layout;
  2. match a research question to the structure that can answer it;
  3. write the model with the subscripts and terms each structure requires.

Cross-sectional data: many units, one point in time

Each row is a different unit (individual, household, firm or country), all observed at roughly the same time.

The model carries the unit subscript \(i\):

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \dots + \beta_k x_k + u$$ $$y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \beta_3 x_{3i} + \dots + \beta_k x_{ki} + u_i$$ $$Wage_i = \beta_0 + \beta_1 Educ_i + \beta_2 Exp_i + \beta_3 Age_i + \beta_4 Male_i + \beta_5 CGPA_i + u_i$$

Time-series data: one unit, many periods

Each row is a different period for the same unit, usually a country.

The subscript is \(t\). One city or one country over time:

$$y_t = \beta_0 + \beta_1 x_{1t} + \beta_2 x_{2t} + \beta_3 x_{3t} + \dots + \beta_k x_{kt} + u_t$$ $$Crimerate_t = \beta_0 + \beta_1 Unemp_t + \beta_2 PrisonPop_t + \beta_3 YoungMales_t + u_t$$ $$GDP_t = \beta_0 + \beta_1 EmpRate_t + \beta_2 InfRate_t + \beta_3 NetExp_t + u_t$$

Time series bring their own issues: lags (\(y_{t-1}\)), trends, serial correlation (Newey–West standard errors), and non-stationarity (unit-root tests; cointegration or differencing).

Examiner: With 24 annual observations, every extra lag costs you degrees of freedom. Justify the lag length.

Pooled cross-sections: new units each period

Several cross-sections taken at different times. Different units are drawn each time, independently, from the same population. A unit occasionally appears twice by chance, but you cannot follow anyone over time.

Pooling lets you ask whether relationships changed between periods, and it supports difference-in-differences. Kiel and McClain (1995) studied house prices near a planned incinerator, with houses sold in 1978 (before) and 1981 (after). The hypothesis \(H_0\) is that house prices fall if a house is located near the incinerator, where \(near = 1\) if within 3 km and 0 otherwise.

$$Hprice_i = \beta_0 + \beta_1 near_i + u_i \qquad \text{(1981 only: mixes the effect with pre-existing differences)}$$ $$Hprice_i = \beta_0 + \beta_1\, year81_i + \beta_2\, near_i + \beta_3\, (year81_i \cdot near_i) + u_i$$

\(\beta_3\) is the coefficient of interest: the difference-in-differences estimate of the incinerator's effect.

Panel (longitudinal) data: the same units, many periods

The same units are observed at several points in time. Each row is a unit–period pair.

The model carries both subscripts and, usually, unit and time effects:

$$y_{it} = \beta_0 + \beta_1 x_{1it} + \dots + \beta_k x_{kit} + a_i + u_{it}$$ $$y_{it} = \beta_1 x_{1it} + \dots + \beta_k x_{kit} + a_i + \lambda_t + u_{it} \qquad \text{(two-way fixed effects)}$$ $$Saving_{it} = \beta_1 FinLit_{it} + \beta_2 Income_{it} + a_i + \lambda_t + u_{it}$$

\(a_i\) captures everything about unit \(i\) that does not change over time, observed or not (geography, institutions, culture). \(\lambda_t\) captures shocks common to all units in year \(t\), such as 2020. Fixed effects remove \(a_i\) by comparing each unit with itself over time; random effects assume \(a_i\) is unrelated to the regressors. The Hausman test helps choose between them.

Examiner: If \(a_i\) is in the equation, tell me how you estimate it away. If it is not, tell me why you are sure there is no unobserved heterogeneity.

Matching the data structure to the research question

Table C2.5. Research questions and the structures that can answer them
Research questionStructureWhy
What factors correlate with household income in 2024?Cross-sectionOne point in time is sufficient.
How has the inflation–unemployment relationship in Malaysia evolved?Time seriesOne economy followed over time.
Did a 2020 policy change affect consumption patterns differently in 2024 compared with 2019?Pooled cross-sectionsIndependent samples before and after the change.
Does retirement affect an individual's cognitive decline?PanelYou need to observe the same people before and after retirement.

Key takeaways

  1. Cross-section \(y_i\); time series \(y_t\); pooled cross-sections and panels \(y_{it}\), but only panels follow the same units.
  2. Pooled cross-sections support before/after comparisons and DiD; panels add unit fixed effects.
  3. Write the subscripts and the extra terms (\(a_i\), \(\lambda_t\), lags) that your structure requires.

Worked example: estimating each structure

All four structures are estimated in 05_data_structures.do and its notebook. The pooled and panel datasets are simulated, with known true values, so you can see each estimator succeed or fail.

* 1. Cross-section use "$data/ds_crosssection_students.dta", clear generate byte female = Gender == "Female" regress Final_Score Study_Hours Attendance Sleep_Hours PT_Job HH_Income_k female, vce(robust) * 2. Time series: declare the time variable, then lags work use "$data/ds_timeseries_macro.dta", clear tsset Year newey Inflation Unemployment L.Inflation, lag(2) * 3. Pooled cross-sections: difference-in-differences use "$data/pooled_incinerator_sim.dta", clear regress price i.y81##i.nearinc age rooms area, vce(robust) * 4. Panel: declare unit and time, then fixed effects use "$data/panel_states_sim.dta", clear encode state, generate(state_id) xtset state_id year xtreg saving_rate finlit_index income_k i.year, fe vce(cluster state_id) import statsmodels.formula.api as smf from linearmodels.panel import PanelOLS cs = load("ds_crosssection_students.csv") cs["female"] = (cs["Gender"] == "Female").astype(int) smf.ols("Final_Score ~ Study_Hours + Attendance + Sleep_Hours + PT_Job + HH_Income_k + female", cs).fit(cov_type="HC1") ts = load("ds_timeseries_macro.csv").set_index("Year") ts["Inflation_lag1"] = ts["Inflation"].shift(1) smf.ols("Inflation ~ Unemployment + Inflation_lag1", ts.dropna()).fit(cov_type="HAC", cov_kwds={"maxlags": 2}) pool = load("pooled_incinerator_sim.csv") smf.ols("price ~ y81 * nearinc + age + rooms + area", pool).fit(cov_type="HC1") panel = load("panel_states_sim.csv").set_index(["state", "year"]) PanelOLS.from_formula("saving_rate ~ finlit_index + income_k + EntityEffects + TimeEffects", panel).fit( cov_type="clustered", cluster_entity=True)

Worksheet C2

  1. Identify the structure: (a) DOSM's Household Income and Expenditure Survey 2019 and 2022, with different households in each; (b) the World Bank's GDP series for ASEAN-10, 1990–2023; (c) the Malaysian Labour Force Survey for 2023 alone; (d) Malaysia's quarterly GDP, 2000Q1–2024Q4. (4 marks)

    (a) Pooled cross-sections, since different households are drawn in each round. (b) Panel: the same ten countries every year. (c) Cross-section. (d) Time series.

  2. Write the model for this question, with correct subscripts: “Does minimum-wage coverage affect employment across Malaysia's 13 states, 2012–2022, controlling for state GDP?” Name the term that handles time-invariant state characteristics. (4 marks)

    \(Emp_{st} = \beta_1 Coverage_{st} + \beta_2 \ln GDP_{st} + a_s + \lambda_t + u_{st}\), with \(s\) = state and \(t\) = year. \(a_s\) is the state fixed effect, absorbing time-invariant state characteristics; \(\lambda_t\) absorbs national shocks common to all states. Standard errors are clustered by state.

  3. In the incinerator model, what would \(\beta_2\) (the coefficient on near) measure, and why is it not the effect of the incinerator? (3 marks)

    \(\beta_2\) is the price difference between houses near and far from the site in 1978, before the incinerator was rumoured. It captures pre-existing differences in the neighbourhood (the site was chosen in a cheaper area), not the incinerator. The effect is \(\beta_3\), the extra change in the near group's prices between 1978 and 1981.

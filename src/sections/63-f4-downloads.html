F4Downloads

Keep everything. The offline ZIP contains this whole guide, which works without an internet connection, plus the lecture notes as a PDF, worksheets and templates in Word, the Stata do-files, the Jupyter notebooks and the practice datasets.

Running the code

Stata
Unzip, open Stata, change the working directory to downloads/code (File → Change Working Directory), then run the do-files in order: do 03_data_cleaning.do first, because 04 and 06 use its output. Built-in commands only; Stata 16 or later.
Python
Open the notebooks in Jupyter, VS Code or Google Colab. The first cell installs any missing package. Run 03_data_cleaning.ipynb before 04 and 06. On Colab the data load from this guide's GitHub repository automatically.
Tested
Every do-file and notebook is run automatically each time this guide is rebuilt, and must finish without a single error before the ZIP is produced.
